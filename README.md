# LOCA+

LOCA+ brand website for `locaplus.cn`, built with Next.js, TypeScript, and Tailwind CSS.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Vercel Deployment

Import this folder into Vercel as a Next.js project. No backend, database, or environment variables are required for the current single-page website.
